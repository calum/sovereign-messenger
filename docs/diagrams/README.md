# Diagrams

The three diagrams in the main README. The `.png` files are what the README shows, so they display in any viewer. The `.mmd` files are the [Mermaid](https://mermaid.js.org) source they were made from.

To regenerate one after editing its source:

```bash
npx @mermaid-js/mermaid-cli -i architecture.mmd -o architecture.png -b white -s 2
```
